# SIEM Lab

A hands-on home lab built to develop and demonstrate practical blue team skills. Built around Wazuh SIEM with intentionally vulnerable targets for detection and analysis practice.

## Lab Environment

| Component | Details |
|---|---|
| SIEM | Wazuh — log aggregation, alerting, threat detection |
| Attack Target | Metasploitable 3 — intentionally vulnerable VM |
| Attacker Machine | Kali Linux |
| Host | TrueNAS server, Lab VLAN isolated |

## Scripts

Custom Python tools built to support lab work and demonstrate scripting ability.

| Script | Description |
|---|---|
| `docs/scripts/scanners/port_scanner.py` | TCP port scanner with configurable host and port range |

## Skills Demonstrated

- SIEM deployment and configuration
- Log analysis and alert tuning
- Network reconnaissance scripting (Python)
- Vulnerability assessment in isolated lab environments
- Security documentation and reporting
